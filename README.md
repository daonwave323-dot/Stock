# 스톡 리밸런싱 · Stock Rebalancing

여섯 지표로 오늘의 자리를 재고, 계획한 비중으로 다시 맞추는 개인용 투자 도구입니다.
빌드 도구 없이 순수 HTML/CSS/JS로 만든 단일 페이지 앱이며, GitHub Pages에서 그대로 뜹니다.

- 사이트: https://daonwave323-dot.github.io/stock-rebalancing/
- 글 · Verdictjang

## 화면

| 주소 | 화면 |
|---|---|
| `#/` | 오늘 — 두 점수, 내 자리(시장·계좌), 최근 판단 채점, 오늘 할 일, 폭락 6사례·읽을거리 미리보기, 아침 메일 미리보기 |
| `#/score/ndx`, `#/score/sox` | 점수 상세 — 지표 여섯의 값·변환값·기여도, 판정 사다리, 점수 이력, 원본 앱 값 대조 |
| `#/crash`, `#/crash/{id}` | 폭락 6사례 — 표·경로 차트(고점/저점 기준)·고점 당시 지표·지금과 닮은 날 |

| `#/readings`, `#/read/{id}` | 글 |

## 데이터와 계산

`data/` 의 JSON은 안드로이드 앱 원본(v2.7.0, `com.wongang.stocktools`)의 식과 자료로 계산했습니다.

- 특이점 점수 — `core/Singularity.kt` 그대로. 가중치 dd .30 / wrsi .20 / vixr .15 / gap .15 / drsi .10 / vixp .10,
  변환식(NDX는 낙폭 ÷12, SOX는 ÷20), 0~100 클램프, 결측 지표 제외 후 남은 가중치 합으로 나눔, 소수 1자리.
  판정 경계 90/80/70/50.
- 지표 계산 — `core/GaugeBars.kt`. 낙폭은 5년(1260거래일) 최고 종가 대비, 200일선은 200거래일 평균,
  RSI는 와일더 14(주간은 ISO 주 마지막 종가), VIX 비율은 50거래일 평균, 공포 백분위는 252거래일.
- 폭락 사례 — `core/Crash.kt`의 `CrashCase` 자료(1929·1987·2000·2008·2020·2025).
  거리는 네 지표 차이를 각 10눈금으로 나눈 평균이며, VIX가 없는 1929·1987은 세 지표로만 셉니다.
- 기준일 — 점수 2026-11-20 종가, 지수(^NDX) 2026-11-25 종가. 실시간 중계는 2차 판입니다.

사용자 입력(보유·매매일지·원칙·판단)은 서버로 보내지 않고 브라우저 localStorage에만 저장됩니다.
